# Apps 1.1.1 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que quien entre con Apple (o Google) desde la app termine su alta sin dar nombre, correo ni
contraseña; que las apps reciban cambios por EAS Update; que lean precios, IVA y Hold de la web; y que su
modo administración no cuente las cuentas de revisión.

**Architecture:**
- **Web primero:** `POST /api/app/puente-web` entrega un enlace de un solo uso (`generateLink` magiclink).
  `/portal/entrar` lo canjea con `verifyOtp` y lleva a `/portal/registro`. La activación de cuentas de
  Apple deja de poner contraseña.
- **Apps:**
  - lógica pura en `.mjs` (iOS) / `.js` (Android), con espejo de la web y pruebas;
  - `src/precios-servidor.js` con copia local y suscripción;
  - `expo-updates` con `runtimeVersion` por versión.

**Tech Stack:**
- Next.js (App Router), supabase-js (`auth.admin.generateLink`, `verifyOtp`), `node --test`.
- Expo SDK 57 (iOS) y 54 (Android), `expo-updates`, AsyncStorage, EAS.

**Spec:** `docs/superpowers/specs/2026-10-08-app-1-1-1-design.md` (leerlo antes de cada tarea).

## Global Constraints

- Rama `app-1.1.1`, worktree `C:\Users\PC\morcast-wt\app111`. Web en `Web/`, apps en `App IOS/` y `App Android/`.
- **Dos apps, mismos cambios.** iOS importa `.mjs`; Android usa `.js` con el mismo contenido. iOS llama a
  la web con `postWeb("/api/app/<ruta>")` (`src/api-web.js`); Android con `postApp("<ruta>")`.
- **NUNCA** se le pide a un usuario de Apple nombre, correo ni contraseña después de entrar.
- **Sin datos de precios → Hold.** Una app nunca enseña montos inventados a un cliente real.
- El 16 % se suma **solo** si `requiereFactura`. El texto de condiciones es exactamente:
  `"Los precios no incluyen IVA. A quien requiere factura se le suma el 16% sobre el subtotal."`
- La cuenta de revisión (`esCuentaDeMuestra()`) conserva su catálogo de ejemplo y queda fuera del Hold.
- **NO** push a `main`, **NO** builds de EAS, **NO** `eas update`, **NO** tocar producción: todo eso lo
  autoriza o lo corre Luis al final (Task 11).
- Textos en español de México, con tuteo, como el resto de la app.

## Review Focus

1. **Puente con un token de chofer o admin, o sin token:** se rechaza. Nunca se genera un enlace para un
   correo distinto al del token (Task 1).
2. **Enlace de `/portal/entrar` ya usado o caducado:** mensaje claro y ninguna sesión a medias.
   `a=https://otro.sitio` no redirige fuera (Task 2).
3. **Apple activado sin contraseña:** "Ya me activaron — revisar" entra directo y el panel no enseña
   ninguna contraseña. Google sigue recibiendo la suya (Task 3).
4. **App sin señal en la primera apertura (sin copia guardada):** sigue en Hold. Con la copia guardada usa
   esa. Si el servidor dice `hold:false` pero falla después, no vuelve a precios de ejemplo (Tasks 4 y 5).
5. **Concepto con `precio:null` en la app:** "Precio por confirmar", sin botones de cantidad y sin sumarse.
   El PDF tampoco lo incluye (Task 6).

```js
 * PUENTE DE SESIÓN APP → WEB (8-oct-2026, Apple guía 4).
 *
 * Quien entró con Apple (o Google) en la app termina su alta en la web SIN
 * volver a iniciar sesión ni dar nombre, correo o contraseña: la app pide un

export const DESTINOS_PUENTE = ["registro", "portal"];

export function destinoPuente(a) {
  return DESTINOS_PUENTE.includes(a) ? a : "registro";
```

```js
import { destinoPuente, urlPuente, puedeUsarPuente } from "@/lib/puente-web.mjs";

const SITIO = (process.env.NEXT_PUBLIC_SITIO || "https://morcast.mx").replace(/\/+$/, "");

export async function POST(peticion) {
  const r = await entrarApp(peticion, {
    roles: ["pendiente", "cliente"],
    freno: { nombre: "app-puente-web", maximo: 10, minutos: 60 },
  });
  if (r.respuesta) return r.respuesta;
  if (!puedeUsarPuente(r.perfil?.rol)) {
    return responder({ ok: false, motivo: "Esta cuenta entra al panel, no al portal." }, 403);
  }
  const correo = r.usuario?.email;

    return responder({ ok: false, motivo: "No se pudo abrir la página. Inténtalo otra vez." }, 500);

  return responder({ ok: true, url: urlPuente({ sitio: SITIO, hashedToken: hashed, destino: destinoPuente(r.cuerpo?.a) }) });
}
```

```js
/**
 * ¿La cuenta entra con "Continuar con Apple"? (8-oct-2026, Apple guía 4.)
 * A esas cuentas NO se les pone contraseña al activarlas: Apple exige que
 * quien entra con Apple no tenga que crear ni recibir una.
 */
export function esCuentaApple(usuario) {
  if (!usuario) return false;
  const meta = usuario.app_metadata || {};
  if (meta.provider === "apple") return true;
  if (Array.isArray(meta.providers) && meta.providers.includes("apple")) return true;
  return Array.isArray(usuario.identities) && usuario.identities.some((i) => i?.provider === "apple");
}
```

```js
import AsyncStorage from "@react-native-async-storage/async-storage";

/**
 * PRECIOS DESDE LA WEB (8-oct-2026). La app ya no trae precios ni Hold
 * escritos en el código: los pide a /api/app/precios (la misma regla que la
 * web) y guarda la última respuesta buena por si no hay señal.
 * Sin respuesta ni copia → `null` → la app se queda en Hold (precios-logica).
 */
const LLAVE = "morcast:precios:v1";
let actual = null;
const oyentes = new Set();
const avisar = () => oyentes.forEach((f) => f(actual));

export function respuestaPrecios() { return actual; }

export async function iniciarPrecios() {
  try {
    const guardado = await AsyncStorage.getItem(LLAVE);
    if (guardado && !actual) { actual = JSON.parse(guardado); avisar(); }
  } catch { /* sin copia: se queda en Hold hasta que conteste el servidor */ }
}

export async function cargarPrecios() {
  const r = await postWeb("/api/app/precios", {});
  if (!r?.ok || !Array.isArray(r.conceptos)) return;
  actual = { hold: r.hold === true, iva: r.iva, requiereFactura: Boolean(r.requiereFactura), conceptos: r.conceptos };
  avisar();
  try { await AsyncStorage.setItem(LLAVE, JSON.stringify(actual)); } catch { /* la memoria basta */ }
}

export async function olvidarPrecios() {
  actual = null; avisar();
  try { await AsyncStorage.removeItem(LLAVE); } catch { /* nada */ }
}

export function usePrecios() {
  const [valor, setValor] = useState(actual);
  useEffect(() => { oyentes.add(setValor); setValor(actual); return () => oyentes.delete(setValor); }, []);
  return valor;
}
```
